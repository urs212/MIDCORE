지구 맵 기반 유럽 대륙 국가 전쟁 서버

서버 개요

미드코어(MidCore)는 지구 맵을 기반으로 펼쳐지는 대규모 유럽 국가 전쟁 서버입니다.
단순한 생존을 넘어, 유럽 대륙에서 국가를 세우고 상대의 코어(Core)를 파괴하여 영토를 점령하세요.

* 본 서버는 유저 후원금과 웹사이트 광고비로 운영됩니다.

리소스팩 필수 설치

코어 시스템 사용을 위해 전용 리소스팩이 반드시 필요합니다.

리소스팩 다운로드 (PC 전용)

※ 반드시 컴퓨터에서 접속하여 다운로드해 주세요.

서버 이용 규칙 (필독)
🚫 핵 / 치트 절대 금지

안티치트 시스템이 상시 운영됩니다. 적발 시 경고 없이 즉시 영구 밴 처리됩니다.

🚫 테러 금지

무차별 파괴, 반복 공격, 서버 운영 방해 행위는 즉시 제재 대상입니다.

🚫 동맹 금지 (중요)

국가 간 동맹, 담합, 불가침 조약은 전면 금지되어 있습니다. 확인 즉시 경고 없이 영구 밴됩니다.
